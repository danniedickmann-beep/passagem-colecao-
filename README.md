# Passagem de Coleção

MVP operacional em React/Vite para acompanhar peças, passagens técnicas, decisões e retornos do fluxo de coleção.

## Acessar o MVP

**[Abrir o Nexus — Passagem de Coleção](https://danniedickmann-beep.github.io/passagem-colecao-/)**

Consulte [CONFIGURACAO.md](CONFIGURACAO.md) para executar, configurar o Supabase e preparar o GitHub Pages.

## Estado desta versão

- build de produção configurado;
- modo local disponível quando o Supabase não está configurado;
- schema mínimo em `supabase/schema.sql`;
- automação de GitHub Pages em `.github/workflows/deploy-pages.yml`;
- versão legada preservada apenas para consulta em `index-legacy.html`.

Antes de uma publicação aberta, substitua a identificação por nome por autenticação real e restrinja as políticas RLS do Supabase.
